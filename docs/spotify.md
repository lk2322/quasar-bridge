# Spotify вместо Яндекс Музыки: маршрут `spotify`

Quasar Bridge перехватывает музыкальные фразы («Алиса, включи Кино») после облачного
распознавания и до того, как Яндекс их выполнит. Запрос отменяется у Яндекса
(`CancelRequest`, local execution), а музыка включается через Spotify Web API на
Spotify Connect-приёмнике самой колонки (spotifyd или librespot). Яндекс Музыка при этом
не запускается вообще, гонки с Алисой нет.

**Статус:** на колонке не проверялось. Проверены разбор фраз, контроллер на имитации
Web API, маршрутизация движка (юнит-тесты, `go test -race`) и сборка под `linux/arm` и
`linux/arm64`.

## Что понадобится

1. Quasar Bridge в режиме `hybrid` — [руководство](guide.md).
2. Spotify Connect-приёмник на колонке, **вошедший в аккаунт**: spotifyd или librespot с
   сохранённым входом. Колонка должна быть видна в списке устройств Spotify с телефона
   в другой сети. Приёмник, который виден только через zeroconf в локальной сети, Web API не
   показывает.
3. Spotify Premium: без него Web API не управляет воспроизведением.
4. Своё приложение на [developer.spotify.com](https://developer.spotify.com/dashboard):
   API — Web API, Redirect URI — `http://127.0.0.1:5589/callback`.

## Вход

На компьютере с браузером:

```sh
go run ./cmd/spotify-login -client-id <Client ID>
scp -P 2222 spotify-token.json root@<IP колонки>:/data/opt/quasar-bridge/
```

Вход идёт по PKCE, секрет приложения не нужен. Файл содержит refresh-токен, права у него
`600`. Spotify может менять refresh-токен при каждом обновлении, и Bridge сам перезаписывает
файл. Если вход перестал действовать, Алиса скажет об этом — повторите `spotify-login`.

## config.json

```json
"spotify": {
  "enabled": true,
  "device": "Мини 3",
  "token_file": "spotify-token.json",
  "mode": "replace",
  "announce": false,
  "active_minutes": 60
}
```

| Поле | Что задаёт |
|---|---|
| `device` | имя приёмника в Spotify, как `device_name` у spotifyd |
| `token_file` | файл из `spotify-login`; относительный путь — от каталога `config.json` |
| `mode` | `replace` — все музыкальные фразы; `explicit` — только с «в Спотифай» |
| `market` | необязательный код страны для поиска; по умолчанию Spotify берёт страну аккаунта. `from_token` требует права `user-read-private`, которое `spotify-login` не запрашивает |
| `announce` | `true` — Алиса говорит «Включаю …»; по умолчанию молча, ответ — сама музыка |
| `active_minutes` | сколько минут после игры Spotify «пауза», «дальше» и «продолжи» идут ему |

## Фразы

| Фраза | Что включается |
|---|---|
| «включи Кино», «поставь Daft Punk» | исполнитель, если имя совпало; иначе трек |
| «включи песню Группа крови», «… группы Кино» | трек внутри своего альбома, дальше играет альбом |
| «включи альбом Discovery» | альбом |
| «включи плейлист дорога», «мой плейлист …» | сначала свои плейлисты, потом поиск |
| «включи группу Кино», «песни Кино», «что-нибудь из Кино» | исполнитель |
| «включи музыку из фильма Интерстеллар», «саундтрек к …» | альбом-саундтрек |
| «включи музыку», «мои треки», «мою волну», «мои лайки» | любимые треки с случайного места |
| «включи Spotify» | продолжить последнее на колонке |
| «пауза», «продолжи», «дальше», «назад», «сначала» | управление, пока Spotify активен |

Если поиск ничего не дал, запрос повторяется без падежных окончаний: «Маркула» → «Маркул».
Имя исполнителя сверяется с учётом транслита: «дафт панк» → Daft Punk.

## Что остаётся Алисе

Свет и другие устройства, таймеры, будильники, напоминания, радио, сказки, подкасты,
новости, звуки природы, громкость и всё, где назван Яндекс. Если правило маршрутизации
отправляет фразу в `home` или `llm`, оно важнее Spotify. Когда Алисе уходит радио, сказка
или Яндекс Музыка, Bridge ставит Spotify на паузу, чтобы они не играли вместе.

Если в момент «включи …» у Алисы играет или стоит на паузе своя музыка, вместе с ответом
уходит `audio_stop`, и её плеер не продолжит играть под Spotify.

## Ограничения

- Не проверено на колонке. Особенно: ответ без голоса (`silent`) и `announce: true`
  вместе с `audio_stop`.
- Короткие команды без «Алиса» («пауза», «громче») распознаёт сама колонка, мимо Bridge.
  Для Spotify они не работают; нужен [bt-proxy](https://hackalice.me/recipes/bt-proxy/).
- Без bt-proxy Алиса не знает, что играет Spotify: не приглушает его, пока слушает.
- Приложениям, созданным после ноября 2024 года, Web API не отдаёт алгоритмические и
  редакционные плейлисты Spotify. Поэтому «моя волна» здесь — любимые треки.
- spotifyd и librespot отклоняют запуск списком треков (`uris`) с ошибкой «Restriction
  violated». Поэтому всё запускается контекстом: альбом с нужного трека, исполнитель,
  плейлист, «Любимые треки» (`spotify:user:<id>:collection`).
- В журнал не пишутся тексты фраз и запросы поиска — только тип запроса и результат.
